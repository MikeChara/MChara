# Mike Chara

Personal author website for Mike Chara, covering writing, projects, books, and recipes.

## Development

```bash
npm install
npm run dev
```

## Commands

```bash
npm run lint
npm run build
npm start
```

## Content

- Journal posts: `src/lib/content.ts`
- Recipes: `src/lib/recipes.ts`
- Images: `public/images/`
- SEO metadata: `src/lib/seo.ts`
